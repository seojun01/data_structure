
## 이진트리의 구현과 데이터 순회
### 빅오(O)와 세타(Θ)
- n이 커질 때 걸리는 시간(높이)이 얼마나 커지는지 말하는 두 가지 방법
- #### 빅오 · 천장(상한)
	- "이것보다 커지지는 않는다"
	- n = 1000일 때 높이 h의 범위 : 0 ~ 10
	- h = O(log n)
- #### 세타 · 천장 + 바닥
	- "딱 이만큼씩 커진다"
	- n = 1000일 때 높이 h의 범위 : 9 ~ 10
	- h = Θ(log n)
### 완전 이진 트리의 노드 수와 높이
- #### 노드 수의 범위를 알면 높이 구할 수 있음
	- h = 0 : min = 1 : max = 1 : n = 1
	- h = 1 : min = 2 : max = 3 : 2 <= n <= 3
	- h = 2 : min = 4 : max = 7 : 4 <= n <= 7
	- h = 3 : min = 8 : max = 15 : 8 <= n <= 15
	- ##### 일반화
		- 2^h <= n <= 2^h+1 - 1 => h |log2n| -> h = O(log n)
		- 높이는 log n을 넘지 않고(O), 최소 노드 수 2^h 때문에 log n보다 작아지지도 않음(Θ)
### 이진트리의 구현 원리
- #### 복습 : Heap
	- 완전 이진 트리인 힙은 인덱스 규칙만으로 배열에 담을 수 있었음![[스크린샷 2026-11-03 at 13.15.38 2.png]]
- #### 원리
	- 동적 배열로 표현하기 어려운 보편적 이진트리를 해결하기 위해 연결 리스트의 prev / next 처럼 자식 노드를 링크로 연결하는 방식이 필요함
	- ##### 노드 한 개의 모양
		- | data | left | right |
		- | self.data | self.left | self.right |
		- ```python
		  class BinaryTreeNode:
		      def __init__(self, data):
		          self.data = data
		          self.left = None
		          self.right = None
		  ```
		- 새로 만든 노드는 자식이 없으므로 None
	- ##### 트리 만들기
		- ```python
		  n1 = BinaryTreeNode(93)
		  n2 = BinaryTreeNode(38)
		  n3 = BinaryTreeNode(27)
		  
		  n1.left = n2
		  n1.right = n3
		  ```
		- 배열은 위치(Index)로, 링크는 참조(left, right)로 자식을 찾는다
- #### 레벨 순회
	- 규칙
		- 레벨? Root에서 몇 번 내려왔는지를 뜻함
		- Root는 level 0
		- 규칙 1. 위에서 아래로
			- Level 0 -> 1 -> 2 -> 3, Root에 가까운 층부터 방문
		- 규칙 2. 왼쪽에서 오른쪽으로
			- 같은 Level 안에서는 왼쪽 노드부터 방문![[스크린샷 2026-11-03 at 13.22.25 2.png]]
			- 방문 순서 : A -> B -> C -> D -> E -> F
	- Queue를 이용한 Level-order Traversal
		- Queue가 빌 때까지 출력 -> 자식 enqueue -> dequeue를 반복
### 우선 탐색 개념
- #### 너비 우선 탐색 (BFS)
	- 인접한 노드를 우선 방문
	- Level-order 순회
	- Queue를 이용하여 구현
- #### 깊이 우선 탐색 (DFS)
	- 갈 수 있는 가장 깊은 곳까지
	- Pre / In / Post-order 순회
	- 재귀를 이용하여 구현
	- ##### Tree & Subtree
		- 루트 노드는 좌우측 자식 노드를 모두 지니며, 좌측 자식을 루트 노드로 하는 또 다른 트리를 생각할 수 있음
		- 주어진 트리에 대하여, 루트 노드의 좌측 자식을 새로운 루트 노드로 삼는 트리를 왼쪽 서브트리라고 정의
		- 같은 방식으로 우측 자식을 루트 노드로 삼으면 오른쪽 서브트리
	- ##### 재귀적 순회
		- 전위 순회 : Root Node > Left Subtree > Right Subtree
			- ```python
			  def pre_order(node):
			      if node == None:
			          return
			      print(node.data)
			      pre_order(node.left)
			      pre_order(node.right)
			  ```
			- 1. 멈춤 조건 : 자식이 없는 자리에 오면 바로 돌아감
			- **2. 루트 노드 찍기 : 지금 노드의 값을 가장 먼저 출력**
			- 3. 왼쪽 서브트리 돌기 : 왼쪽 자식을 새 루트로 삼아 같은 함수 호출
			- 4. 오른쪽 서브트리 돌기 : 왼쪽이 다 끝나면 오른쪽 자식으로 똑같이 호출
		- 중위 순회 : Left Subtree > Root Node > Right Subtree
			- ```python
			  def in_order(node):
			      if node == None:
			          return
			      pre_order(node.left)
			      print(node.data)
			      pre_order(node.right)
			  ```
			- 1. 멈춤 조건 : 자식이 없는 자리에 오면 바로 돌아감
			- 2. 왼쪽 서브트리 돌기 : 왼쪽 자식을 새 루트로 삼아 같은 함수 호출
			- **3. 루트 노드 찍기 : 지금 노드의 값을 가장 먼저 출력**
			- 4. 오른쪽 서브트리 돌기 : 왼쪽이 다 끝나면 오른쪽 자식으로 똑같이 호출
		- 후위 순회 : Left Subtree > Right Subtree > Root Node
			- ```python
			  def post_order(node):
			      if node == None:
			          return
			      pre_order(node.left)
			      pre_order(node.right)
			      print(node.data)
			  ```
			- 1. 멈춤 조건 : 자식이 없는 자리에 오면 바로 돌아감
			- 2. 왼쪽 서브트리 돌기 : 왼쪽 자식을 새 루트로 삼아 같은 함수 호출
			- 3. 오른쪽 서브트리 돌기 : 왼쪽이 다 끝나면 오른쪽 자식으로 똑같이 호출
			- **4. 루트 노드 찍기 : 지금 노드의 값을 가장 먼저 출력**
- #### 시간 복잡도
	- ##### 이진 트리
		- 탐색 : O(n)
		- 삽입 : O(n)
		- 삭제 : O(n)
	- ##### 완전 이진 트리
		- 탐색 : O(n)
		- 삽입 : O(n)
		- 삭제 : O(n)
### 탐색(Search)
- #### 이진 탐색
	- *업다운 게임처럼 반으로 쪼개서 물어보기*
	- 정렬된 수 15개에서 46 찾기![[스크린샷 2026-11-03 at 13.36.07.png]]
	- 조건 : 수가 작은 것부터 큰 것 순서로 정렬되어 있어야 절반 버릴 수 있음
- #### 이진 탐색 트리
	- 어떤 노드든 왼쪽 서브트리에는 자신보다 작은 값만 존재
	- 어떤 노드든 오른쪽 서브트리에는 자신보다 큰 값만 존재
- #### 이진 탐색 트리와 Heap
	- ##### 이진 탐색 트리
		- 값 규칙 : 왼쪽 자식 < 부모 < 오른쪽 자식
		- 모양 규칙 : 없음
	- ##### Heap (Max Heap)
		- 값 규칙 : 부모 >= 자식
		- 모양 규칙 : 완전 이진 트리
