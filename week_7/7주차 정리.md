
### 그래프와 트리 필요한 이유
- 연결 리스트, 스택, 큐는 모두 선형 구조임
- 여러 방향의 연결은 표현할 수 없음
- 현실의 데이터는 여러 방향으로 연결된 데이터가 많음
- -> 그래서 비선현 자료구조 필요 (계층 관계는 트리, 자유로운 연결 관계는 그래프)
### 트리와 이진트리 기본 용어
- #### 그래프 Graph
	- 두 대상 사이의 관계를 꼭짓점과 모서리로 나타내는 자료구조
	- G = (V, E)
		- V 꼭짓점의 집합
		- E 모서리의 집합
	- 인접 adjacent : 모서리로 바로 이어진 두 꼭짓점 
	- 차수 degree : 한 꼭짓점에 붙은 모서리의 개수
	- 경로 path : 모서리를 따라 이동한 꼭짓점의 순서
	- ##### 그래프 위를 걷는 방법
		- Walk (보행)
			- 한 꼭짓점에서 출발해 모서리를 따라 이동한 꼭짓점과 모서리의 연속
			- 길이 = 지나간 모서리의 개수
		- Trail (소로)
			- 모서리는 다시 못 지남, 꼭짓점은 가능
		- Path (경로)
			- 꼭짓점도 모서리도 다시 지나지 않음
		- Cycle (순환)
			- 시작과 끝이 같고, 그 밖의 반복은 없음
- #### 트리 Tree
	- Cycle 없이 연결된 그래프, 노드는 부모와 자식으로 이어짐
		- 다음 두 조건을 모두 만족하는 그래프를 트리라고 함
			- 연결 그래프 : 어떤 두 노드 사이에도 길이 있음
			- Cycle이 없음 : 제자리로 돌아오는 길이 없어 아래로만 갈라짐
	- 노드 Node : 트리의 동그라미 하나하나, 값을 담음
	- 간선 Edge : 노드와 노드를 잇는 선, 부모-자식 관계를 뜻함
	- 부모,자식 : 바로 위가 부모, 바로 아래가 자식임
	- (노드가 n개면 간선은 반드시 n-1개)
	- level : 루트가 0, 한 칸 내려갈 때마다 1씩 커짐
	- height : 가장 깊은 노드의 레벨
	- degree : 한 노드가 가진 자식의 수
	- sibling : 부모가 같은 노드끼리
	- 조상, 자손 : 위로 이어진 모두가 조상, 아래는 자손
	- subtree : 어떤 노드와 그 아래 전부가 이루는 트리
### 이진트리의 종류
- #### 루프 노드와 리프 노드
	- 부모가 없는 노드 하나가 루트
	- 자식이 없는 노드는 리프, 단말 노드라고도 함
	- 리프가 아닌 나머지는 모두 내부 노드
- #### 이진 트리
	- 모든 노드의 자식이 최대 2개인 트리
	- 자식은 왼쪽, 오른쪽으로 구분되고, 하나만 있어도 자리는 남음
	- 그래서 어떤 노드의 자식 수는 0, 1, 2 중 하나
- #### 포화 이진트리
	- 모든 레벨이 하나도 빠짐없이 꽉 차있음
	- 높이가 h면 노드는 2^(h+1) -1 개로 정해짐
	- 노드 수 공식
		- 레벨 k의 노드 수 = 2^k
		- 높이 h의 전체 노드 수 = 2^(h+1) - 1
- #### 완전 이진트리
	- 오른쪽 한 자리가 비어 있음
	- 마지막 레벨만 덜 차있음
	- 왼쪽부터 순서대로 채워야 완전 이진트리임
	- 배열로 담는 규칙
		- i번 노드의 왼쪽 자식 = 2i + 1, 오른쪽 자식 = 2i + 2
		- i번 노드의 부모 = (i - 1) / 2의 몫
- #### 편향 이진트리
	- 모든 노드가 한쪽 방향으로만 자식을 가짐
	- 사실상 연결 리스트라 트리의 장점을 잃음
### Heap의 삽입과 삭제
- #### Heap 힙
	- 완전 이진트리임
	- 모든 부모가 자식보다 크거나 같은 값을 가짐
- #### Max Heap
	- 모든 부모가 자식보다 크거나 같음
	- 루트에는 항상 최댓값이 놓임
- #### Min Heap
	- 부모가 자식보다 작거나 같으면 Min Heap이라 부름
	- 형제끼리의 크기 순서는 정해지지 않음
	- 정렬된 트리가 아니라 루트만 보장됨
- #### Heap 삽입
	- 1. 마지막 자리에 넣는다
	- 2. 부모와 비교한다
	- 3. 교환하고 멈춘다
	- 삽입 위치는 완전 이진트리를 지키기 위해 마지막 자리로 고정됨
	- 위로 올리며 규칙을 되돌림
	- 그 뒤 부모와 비교, 교환을 반복하는데, 루트까지 올라가도 높이만큼이면 끝남
- #### Heap 삭제
	- 힙은 중간 값을 지우지 않는다 - 꺼내는 값은 루트 하나만
	- 루트가 비어도 트리가 무너질 수는 없으니, 기존 노드 하나가 그 자리를 대신해야 함
	- 그 자리를 대신할 수 있는 노드는 마지막 노드 하나뿐임
	- 1. 마지막 노드를 루트로
	- 2. 더 큰 자식과 교환
	- 3. 한 번 더 내려가고 멈춤
	- 마지막 노드를 루트로 올리는 것은 완전 이진트리 모양을 지키기 위함
### Heap 구현과 우선순위 큐
- #### Heap은 배열 index로 구현할 수 있을까?
	- 일반 이진트리
		- 노드 위치가 고정되어 있지 않음
		- -> 노드마다 인덱스를 매기는 접근이 어려움
	- 힙 = 완전 이진트리
		- 노드 배치 순서가 명확함
		- -> 동적 배열로 힙을 구현할 수 있음
- #### 파이썬으로 힙 구현
	- ```python
	  class MaxHeap:
	      def __init__(self):
	          self.h = []
	          
	      def push(self, x):
	          self.h.append(x) # 마지막 자리에 추가
	          i = len(self.h) - 1
	          while i > 0:
	              p = (i - 1) // 2 # 부모 인덱스
	              if self.h[i] <= self.h[p]: # 부모보다 작거나 같으면
	                  break
	              self.h[i], self.h[p] = self,h[p], self.h[i]
	              i = p # 한 칸 위로
	          
	  hp = MaxHeap()
	  print(hp.h)
	  
	  hp.h = [93, 38, 27, 29, 31, 15]
	  hp.push(40)
	  print(hp.h)
	  ```

	- Priority 큐
