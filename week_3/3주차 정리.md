
### 동적 배열의 한계
1. 값이 붙어 있어야 하므로, 중간 삽입, 삭제 때마다 데이터를 밀거나 당겨야 함 -> O(n)
2. 확장할 때 큰 연속 공간을 새로 잡아 전체를 복사해야 함
- 해결책 : 값을 붙여 두지 않고, 각 값이 다음 값의 위치를 함께 저장하게 함
- 값마다 "다음 값의 위치"를 함께 저장해 순서를 유지함 -> 연결 리스트

### 연결 리스트
- #### 연결 리스트의 구조
	- 값 하나를 담는 상자에 "다음 상자의 주소"를 함께 넣는다
	- 노드 = 데이터(data) + 링크(next) -> 값 한 칸과 다음 노드의 주소 한 칸이 한 묶음임
	- head는 첫 노드를 가리키는 변수, 마지막 노드의 next는 None -> 여기서 리스트가 끝남![[스크린샷 2026-10-10 at 16.20.24.png]]
```python
class Node:
	def __init__(self, data):
		self.data = data
		self.next = None
```
- #### 데이터 삽입하기
	1. 신규 노드의 data를 채우고, next를 '직전 노드가 가리키던 노드'로 지정함
	2. 직전 노드의 next를 신규 노드로 바꿈. -> 기존 값은 하나도 움직이지 않음
	- 어떤 위치에 넣더라도, 위 두 과정만 거치면 삽입이 끝남
```python
new = Node('Ade')
new.next = prev.next # 1
prev.next = new # 2
```
- #### 데이터 삭제하기
	1. 삭제 대상의 직전 노드의 next를 '삭제 대상이 가리키던 노드'로 조정함
	2. 아무도 가리키지 않게 된 노드를 제거함 -> 뒤 데이터를 당길 필요가 없음
```python
prev = self.head # 직전 노드부터 찾음
while prev.next is not target:
	prev = prev.next # 한 칸씩 이동 -> O(n)
	
prev.next = target.next # 1. 건너뛰게 만들기
target.next = None # 2. 연결 끊기
self.size -= 1
```
- #### 데이터 탐색하기
	- 연결 리스트는 인덱스로 바로 접근할 수 없음 -> head부터 한 칸씩 따라가야 함
	1. cur을 head에 두고, 찾는 값인지 확인함
	2. 아니면 cur = cur.next로 한 칸 이동 -> None을 만나면 탐색 실패
```python
cur = self.head
while cur is not None: # None이면 끝까지 온 것
	if cur.data == target:
		return cur # 1. 찾음 -> 노드 반환
	cur = cur.next # 2. 한 칸 이동 -> O(n)
return None # 끝까지 못 찾음
```
- #### 파이썬으로 구현
	- ##### Node, SinglyLinkedList
		- Node -> 값 한 칸 + 다음 노드로 가는 링크
		- SinglyLinkedList -> 리스트 전체의 시작점(head)와 개수(size)를 보관
```python
class Node:
	def __init__(self, data):
		self.data = data
		self.next = None
		
class SinglyLinkedList:
	def __init__(self):
		self.head = None
		self.size = 0
```

### 양방햔 연결 리스트 (Doubly Linked List)
- next에 이어 prev까지 가진 구조
- 노드 하나가 prev, data, next 세 칸을 가짐 -> 앞뒤 어느 방향으로도 이동할 수 있음
- 시작과 끝에는 값을 갖지 않는 더미 노드 (head, tail)
- 삭제 시 바로 앞 Node를 탐색할 필요가 없어 삭제가 O(1)로 단순해짐
- 포인터를 하나 더 저장하므로 메모리를 더 쓰고, 갱신할 연결도 늘어남![[스크린샷 2026-10-10 at 16.31.43.png]]
```python
class DNode:
	def __init__(self, data, prev=None, next=None):
		self.data = data
		self.prev = prev
		self.next = next

class DoublyLinkedList:
	def __init__(self):
		self.head = DNode(None)
		self.tail = DNode(None)
		self.head.next = self.tail
		self.tail.prev = self.head
		self.size = 0
```

### 원형 연결 리스트 (Circular Linked List)
- 맨 마지막 Node의 next를 첫 Node와 이어 사이클을 만든 자료구조
- 순서상 뒤에 있는 Node에서도 순회를 거쳐 앞의 Node까지 도달할 수 있음
- 끝이 없으므로 시작점 기준으로 순회 종료 조건을 직접 정해야 함![[스크린샷 2026-10-10 at 16.36.05.png]]
```python
start = last.next
cur = start
while True:
	cur = cur.next
	if cur is start: break
```

### 이중 원형 연결 리스트 (Doubly Circular Linked List)
- 이중 연결 리스트에서 맨 마지막 Node를 가장 첫 Node와 이어 사이클을 만든 자료구조
- next뿐 아니라 prev도 이어지므로 뒤로도 끝없이 순회할 수 있음
- 어느 노드에서 시작하든 양방향으로 전체에 도달 -> 종료 조건은 여전히 직접 정해야 함![[스크린샷 2026-10-10 at 16.37.49 2.png]]
```python
last.next = head
head.prev = last
cur = head
while True:
	cur = cur.prev
	if cur is head: break
```
