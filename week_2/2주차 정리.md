
### 자료구조의 분류
- #### 단순 구조
	- 정수(int), 실수(float), 문자(char), 문자열(string) 등의 기본 자료형
- #### 선형 구조
	- 자료 간 앞뒤 관계가 1:1인 선형 관계
	- 리스트, 연결리스트, 스택, 큐, 덱 등
- #### 비선형 구조
	- 자료 간 앞뒤 관계가 1:N or N:N의 관계
	- 트리, 그래프, 해시테이블 등

### 자료구조와 메모리
- #### Why Heap?
	- Stack : 크기가 정해짐
	- Heap : 필요한 만큼 빌려 씀
		- 값이 사라지면 파이썬이 알아서 정리해 줌 (가비지 컬렉션)
- #### 메모리's Heap & 자료구조's Heap
	- 메모리의 힙
		- 운영체제가 주는 "빈 공간"
		- 리스트와 객체가 실제로 놓이는 그 영역
		- 정렬 규칙 없음
	- 자료구조의 힙
		- 트리 모양의 자료구조
		- 가장 크거나 작은 값을 빨리 꺼내는 용도
		- 우선순위 큐를 만들 때 활용

### 선형 구조
- #### 연결리스트 (Linked List)
	- 메모리 여기저기 흩어져 저장
	- 포인터로 연결
	- 접근 속도 느림
	- 삽입 / 삭제 비교적 빠름 (포인터 바꾸기)
	- 크기 가변
- #### 스택 (Stack)
	- LIFO(Last In First Out) : 가장 나중에 넣은 데이터를 가장 먼저 꺼냄
	- 핵심 연산 : push, pop, peek (최하위 원소 확인)
- #### 큐 (queue)
	- FIFO (First In First Out)
	- 스택과 마찬가지로 합입과 삭제의 위치가 제한된 유한 순서 리스트
	- 뒤에서는 삽입만, 앞에서는 삭제만 할 수 있는 구조
	- 먼저 삽입한 원소가 먼저 삭제되는 선입선출 구조

### 비선형 구조
- #### 해시테이블 (Hash Table)
	- key:value 한 쌍으로 저장하는 자료구조 (map)
	- 해시 함수가 키를 배열의 인덱스로 변환해 값을 저장 및 조회
	- 탐색, 삽입, 삭제 평균 O(1)
- #### 이진 트리 (Binary Tree)
	- 데이터를 계층 구조(부모-자식)로 저장하는 자료구조
		- root : 가장 위에 있는 시작 노드
		- 부모, 자식 : 바로 위 / 아래로 연결된 노드
		- 리프(leaf) : 자식이 없는 끝 노드
		- 레벨, 높이 : 루트에서 내려온 단계의 수
		- 서브트리 : 어떤 노드와 그 아래 전체
	- ##### 이진 트리 순회 (Traversal)
		- 모든 노드를 한 번씩 방문하는 방법
		- 루트를 처음(전위), 중간(중위), 마지막(후위)에 방문함
	- ##### 이진 탐색 트리 (BST, Binary Search Tree)
		- 왼쪽은 나보다 작은 값, 오른쪽은 나보다 큰 값 -> 값을 빠르게 찾을 수 있음
- #### 그래프 (Graph)
	- 정점(vertex)와 간선(edge)으로 연결 관계를 표현하는 자료구조
		- 정점 : 데이터를 담는 점
		- 간선 : 두 정점을 잇는 선
		- 차수(degree) : 한 정점에 연결된 간선의 개수
		- 경로, 사이클 : 정점을 따라 이동한 길 / 제자리로 돌아오는 길
	- ##### 그래프 탐색 : BFS, DFS
		- 모든 정점을 빠짐없이 방문하는 방법
			- 큐를 쓰면 BFS, 스택을 쓰면 DFS
			- 너비 우선 탐색 (BFS)
				- Breadth First Search
				- 큐(FIFO) 사용 -> 가까운 곳부터 넓게
			- 깊이 우선 탐색 (DFS)
				- Depth First Search
				- 스택(LIFO) 사용 -> 한 길로 끝까지

### 시간복잡도
- 입력 데이터가 n개일 때, 코드가 계산을 몇 번 하는지 세는 것
- '초'가 아닌 횟수로 세는 이유 -> 컴퓨터 성능마다 걸리는 시간이 달라서 공평한 비교가 어려움
- #### Big-O 표기법
	- ##### Why O?
		- O = Order(차수, 규모)의 첫 글자 -> "대략 이 정도 규모로 커진다"는 뜻
		- O(n)은 입력이 2배면 계산도 대략 2배
	- ##### Rules
		- 곱해진 숫자(상수)는 지움 : 2n -> O(n), n/2 -> O(n)
		- 가장 크게 자라는 항만 남김 : n^2 + n -> O(n^2)
	- ##### Example
		- 3n^2 + 5n + 7 -> O(n^2)
			- 상수 지우기 -> n^2 + n
