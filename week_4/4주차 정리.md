
### 스택 (Stack)
- 가장 나중에 넣은 데이터(원소)가 가장 먼저 나오는 LIFO(Last In First Out) 구조
- 데이터의 입출력이 top 한 곳에서만 일어남
- 중간 데이터에 직접 접근할 수 없고, 위에서부터 꺼내야 함![[스크린샷 2026-10-10 at 16.56.19.png]]
```python
stack = []; stack.append(10); stack.append(20)
stack[-1] # 20
stack.pop() # 20 꺼내기
len(stack) == 0 # False 10이 남아 있음
```

### 재귀호출과 스택의 관계
- 재귀로 쓴 코드 - Stack 이 보이지 않음
```python
def fact(n):
	if n == 1:
		return 1
	return n * fact(n-1)
```
- Stack으로 쓴 코드 - 직접 쌓고 꺼냄
```python
def fact(n):
	stack, result = [], 1
	while n > 1:
		stack.append(n); n -= 1
	while stack:
		result *= stack.pop

return result
```
- 재귀가 편한 문제는 재귀로, 깊이가 깊거나 흐름을 통제해야 하면 stack으로 바꿔 씀
- #### 피보나치 수
- 재귀로 쓴 코드 - 호출이 두 갈래로 뻗음
```python
def fibo(n):
	if n == 1 or n == 2:
		return 1
	return fibo(n - 1) + fibo(n - 2)
```
- Stack으로 쓴 코드 - 두 값을 쌓고 하나씩 꺼냄
```python
def fibo(n):
	stack = list()
	stack.append(n)
	result = 0
	while stack:
		k = stack.pop()
		if k <= 2: result += 1
		else: stack += [k - 1, k - 2]
	return result
```

### 스택(Stack)의 구현
- 노드와 링크없이 파이썬 list만으로 스택 구현하기
- 동적 배열을 활용한 Python에서의 Stack 생성
	- `stack = list()`
- Stack에 새로운 원소를 push
	- `stack.append(3)`
- Stack의 최상단 원소를 pop
	- `top = stack.pop()`
- 최상단 원소만 확인(peek)
	- `top = stack[-1]`
```python
class Stack:
	def __init__(self):
		self.items = []
	
	def push(self, val):
		self.items.append(val)
		
	def pop(self):
		try:
			return self.items.pop()
		except:
			print("Stack is empty")
		
	def top(self):
		try:
			return self.items[-1]
		except IndexError:
			print("Stack is empty")
	
	def __len__(self):
		return len(self.items)
```
