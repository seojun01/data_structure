
### Queue
- Stack과 달리 큐는 먼저 들어온 데이터가 먼저 나감 (FIFO)
- #### Queue
	- First In First Out 원칙을 따르는 형태의 선형 자료구조
	- Queue는 대기열이라는 뜻으로, 식당 줄서기, 프린트 대기열 등과 유사한 동작 구조
	- 스택에서 push였던 데이터 삽입 -> 큐에서는 enqueue로 구현
	- ##### enqueue
		- 주어진 큐의 최후방에 새로운 데이터를 삽입
		- 스택의 push처럼 enqueue도 삽입 위치가 정해져 있음 (항상 최후방)
	- ##### dequeue
		- 주어진 큐의 최전방에 존재하는 데이터를 제거
- #### 파이썬으로 구현하는 큐
	- 동적 배열을 활용한 파이썬에서의 큐 생성
		- `queue = list()`
	- 큐에 새로운 원소를 enqueue
		- `queue.append(7)`
	- 파이썬은 별도의 큐 타입 없이 동적 배열로 큐 표현 가능
	- append()는 리스트 맨 끝에 원소를 추가하므로 enqueue와 동일한 동작
	- 큐의 최전방 원소를 dequeue
		- `del queue[0]`
		- `queue.pop(0)`
		- dequeue는 del queue\[0], peek은 queue\[0] - 둘다 리스트의 첫 원소를 대상
- #### 동적 배열의 한계
	- 동적 배열에서의 맨 앞 데이터 삭제 (dequeue)
	- 큐는 맨 앞에서 꺼내므로(pop(0)), 첫 데이터를 지우면 뒤쪽 데이터를 모두 한 칸씩 앞으로 당겨야 함
	- 따라서 리스트로 만든 큐의 dequeue는 O(n)
### 환형 Queue
- #### Circular Queue
	- 선형이 아닌 환형 대기열의 형태로 데이터를 제어하는 자료구조
		- 삭제에 비교적 높은 시간복잡도를 요하는 일반 큐 대비 우월
		- 일반적으로 크기를 고정해둔 상태에서 환형 큐를 이용
- #### 환형 큐 구조
	- ##### front
		- 최전방 원소가 있는 칸을 가리킴 (다음 dequeue 위치)
	- ##### rear
		- 다음 원소가 들어갈 빈 칸을 가리킴 (다음 enqueue 위치)
- #### 환형 큐에서의 enqueue
	- 환형 큐에서 enqueue 시도할 경우, REAR가 가리키고 있던 위치에 데이터가 삽입되며 새 데이터 삽입으로 인해 REAR는 한 칸 밀려남
- #### 환형 큐에서의 dequeue
	- FRONT가 가리키던 원소를 꺼내고 FRONT만 한 칸 이동, 남은 값은 나중에 덮어씀
- #### 파이썬으로 환형 큐 구현
	- ```python
	  class CircularQueue:
	      def __init__(self, capacity):
	          self.capacity = capacity
	          self.arr = [None] * capacity
	          self.front = 0
	          self.rear = 0
	          self.count = 0
	      # 큐 상태 출력
	      def display(self):
	          print("배열 : ", self.arr)
	          print(f"front={self.front}, rear={self.rear}, count={self.count}") 
	      # Enqueue 구현
	      def enqueue(self, data):
	          if self.count == self.capacity:
	              print("큐가 가득 찼습니다. (Overflow)")
	              return
	              
	          self.arr[self.rear] = data # 데이터 저장
	          self.rear += 1 # 삽입 위치 증가
	          self.count += 1 # 데이터 개수 증가
	          
	          if self.rear == self.capacity:
	              self.rear = 0 # 배열 끝이면 처음으로
	              
	      def dequeue(self):
	          if self.count == 0:
	              print("큐가 비어 있습니다. (Underflow)")
	              return None
	              
	          del_value = self.arr[self.front] # 맨 앞 데이터 가져오기
	          self.arr[self.front] = None # 자리 비우기
	          self.front += 1 # 삭제 위치 증가
	          self.count -= 1 # 데이터 개수 감소
	          
	          if self.front == self.capacity:
	              self.front = 0 # 배열 끝이면 처음으로
	              
	          return del_value
	  ```

### Deque
- 양쪽 모두에서 데이터를 삽입하고 삭제할 수 있는 자료구조
- #### Double-Ended Queue
	- 데이터 열의 왼쪽 끝과 오른쪽 끝 모두에서 삽입과 삭제가 자유로운 자료구조
	- 스택과 큐의 특성을 합한 형태의 자료구조라 할 수 있음
- #### 양끝에서 모두 가능한 덱의 네가지 연산
	- appendleft(x), popleft(), append(x), pop()
### 우선순위 Queue
- 먼저 들어온 순서가 아니라, 우선순위가 높은 데이터부터 나가는 큐
	- 삽입 순서와 무관하게 우선순위가 다음 순서를 결정 (숫자가 작을수록 높은 우선순위)
- #### Priority Queue
	- 데이터를 넣은 순서와 관계없이, 우선순위가 가장 높은 데이터부터 꺼내는 자료구조
	- 응급실 진료 순서, 운영체제의 작업 스케줄링처럼 중요도가 순서를 정하는 문제에 사용
	- 배열이나 연결 리스트로 구현하면 삽입과 삭제 중 한쪽이 O(n)
- #### 활용
	- 인쇄 대기열, CPU 작업 스케줄링, 네트워크 패킷 처리, 키보드 버퍼, 너비 우선 탐색, 메시지 큐 ...
