
**이중 연결 리스트로 미니 메모장 만들기**

- 이중 연결 리스트와 두 스택을 활용하여 줄 추가·삭제, 현재 줄 이동, 실행취소·재실행이 가능한 콘솔 메모장을 구현함
- 추가 패키지 설치 없이 Python 3.8 이상을 사용함

  

**메모장 기능 구현하기**

- 메모의 각 줄을 노드에 저장하고 prev와 next로 앞뒤 줄을 연결함
- 삽입·삭제 시 양쪽 연결과 처음·마지막 노드를 올바르게 관리함
- prev를 따라 위로, next를 따라 아래로 이동하여 편집할 줄을 선택함
- 두 스택을 활용하여 최근 편집을 취소하고 취소한 편집을 다시 실행함
- 편집을 복원하기 위해 작업 종류, 줄 번호, 줄 내용을 기억함
- 2번째 줄의 “오늘 수업”을 삭제했다면 같은 위치에 같은 내용을 복원함
- 작업 기록의 표현 방식과 보조 메서드 구성은 자유롭게 선택함
- 기록 예시로 ("delete", 2, "오늘 수업") 튜플을 활용함. 딕셔너리 등 다른 방식도 허용함
- 삽입·삭제에 성공하면 실행취소 스택에 기록하고, undo에서 최근 기록을 꺼내 반대 동작을 수행함

**사용할 명령어 (명령어-기능)**

**append 내용 -** 맨 끝에 줄 추가  

**insert 내용** - 현재 줄 앞에 새 줄 삽입. 빈 메모에서는 첫 줄 추가  
**delete** - 현재 줄 삭제  
**up / down** - 편집할 줄을 한 줄 위로 / 아래로 이동  
**print** - 메모 전체 출력. > 표시가 있는 줄이 현재 줄  
**undo / redo** - 최근 편집 취소 / 취소한 편집 다시 실행  
**exit** - 현재 메모 저장 후 종료

  

**제공 코드와 구현 범위**

- 주어진 skeleton 파일의 TODOs 완성
- Stack 기본 연산 4개, DoublyLinkedList 삽입·삭제 2개, Editor 편집·실행취소·이동·저장을 구현함
- 명령 처리, 현재 줄 표시, 커서 관리와 줄 번호 변환 도우미는 제공 코드를 활용하면 됨
- 내부 insert(index, text)/delete(index)는 유지하고, 필요한 보조 메서드는 자유롭게 추가함
- 지각 제출은 1일당 10점 감점하고, 3일 초과 시 미제출로 처리함
- 개념 토론은 허용하되, TODO 코드 복사·공유·대리 작성이 확인되면 관련 학생은 과제 0점으로 처리함

**자료구조 사용 조건**

- 메모는 직접 구현한 이중 연결 리스트에 저장함
- 파이썬 list로 메모 저장을 대신하면 이중 연결 리스트 항목을 0점으로 처리함
- 스택 저장소와 출력·저장용 임시 변환에는 파이썬 list 사용을 허용함
